# 電車ゲーム

スマートフォンの縦画面で遊ぶ電車の落下・合体ゲームを開発中です。現在はフェーズ0の仮画面で、画面を触ると位置を示す丸が表示されます。ゲームのルールと作業順序は `documents/` にあります。

## 必要な環境

- Node.js と npm
- PCとiPhoneを同じWi-Fiに接続できる環境

## PCで起動する

リポジトリのフォルダで次を実行します。

```powershell
npm install
npm run dev
```

ターミナルに表示された `Local` のURLをPCのブラウザで開きます。終了するときはターミナルで `Ctrl+C` を押します。

本番用のファイルを作る場合は、次を実行します。生成物は `dist/` に置かれます。

```powershell
npm run build
```

## iPhoneのSafariで確認する

1. PCとiPhoneを同じWi-Fiにつなぎます。
2. PCのPowerShellで `ipconfig` を実行し、接続中のWi-Fiの「IPv4 アドレス」を確認します。
3. リポジトリのフォルダで次を実行します。

   ```powershell
   npm run dev -- --host 0.0.0.0
   ```

4. iPhoneのSafariで `http://<PCのIPv4アドレス>:5173/` を開きます。Viteが別のポートを表示した場合は、その番号を使います。
5. 縦長の画面が収まり、画面に触れた位置へ黄色い丸が移動することを確認します。

接続できない場合は、PCとiPhoneが同じネットワークにいるか、PC側でViteが起動しているか、WindowsファイアウォールでNode.jsのプライベートネットワーク通信が許可されているかを確認してください。ゲストWi-Fiなど、端末同士の通信を遮断するネットワークでは接続できません。
