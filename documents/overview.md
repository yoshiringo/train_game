# 電車ゲーム — 開発概要

## 1. 目的

子どもとスマートフォンで遊べる「電車ゲーム」を制作する。
ゲームの基本ルール・操作感は「スイカゲーム」にできるだけ近づけ、フルーツの代わりに電車のイラストを使用する。
まずは小さく動くものを作り、細かな仕様・実装手順・ゲームバランスはCodexとの対話で決めながら進める。

## 2. ゲーム概要

- スマートフォンの縦画面で遊ぶ、1人用の2D落下・合体パズルゲーム。
- プレイヤーは電車アイコンの落下位置を左右に調整し、指を離して落とす。
- 同じ種類（同じ進化段階）の電車同士が接触すると合体し、次の段階の電車になる。
- 電車は円形のアイコンとして表示し、重力・衝突・転がりなどを表現する。
- 合体によるスコア加算、次に落ちる電車の表示、ゲームオーバー、リトライ、ハイスコア保存を想定する。
- 進化は全11段階。最終段階の電車の扱いなど、細かなルールは開発時に決める。

## 3. 最重要の独自要件：進化順の並べ替え

- **ゲーム開始前に、11種類の電車の進化順をプレイヤーが自由に並べ替えられるようにする。**
- スタート画面には、11種類の電車アイコンを**2列**で並べ、その下に「ゲームスタート」ボタンを配置する。
- 各アイコンの並び順が、そのままレベル1〜11の進化順となる。
- 並べ替え方法（ドラッグ＆ドロップ、タップで交換など）は、スマホでの操作しやすさを優先してCodexと検討する。
- 「ゲームスタート」を押した時点の進化順を、そのプレイ中のルールとして使用する。
- 使用する電車は**11種類で固定**。具体的な車種・画像・初期順序は後で決める。
- 必要に応じて、前回の並び順を端末内に保存する。

## 4. 画面・デザイン

### スタート画面
- 鉄道・駅・線路・鉄道標識などをモチーフにした、親しみやすいデザイン。
- 11種類の電車を2列で表示し、進化順がひと目で分かるようにする。
- 並べ替え操作と「ゲームスタート」ボタンを用意する。

### ゲーム画面
- スマホ縦画面を基本とする。
- 電車が落下・衝突・合体するプレイ領域、現在のスコア、ハイスコア、次の電車などを表示する。
- 小さな子どもでも直感的に操作できるUIを優先する。

### 画像・音
- 電車のイラストや背景など、必要な画像素材はAI生成を想定する。
- 電車は円形アイコンに収め、サイズは進化段階に応じて大きくする。
- 効果音なども必要に応じて追加する。素材の利用条件・権利関係には配慮する。

## 5. 技術・公開方針

| 項目 | 方針 |
| --- | --- |
| 対象 | スマートフォンのブラウザ（縦画面） |
| ゲームエンジン | Phaser 3 |
| 物理演算 | Matter.js（Phaserから利用） |
| 言語 | JavaScript |
| ビルドツール | Vite |
| 開発 | VS Code + Codex CLI |
| バージョン管理 | Git / GitHub |
| 公開先 | GitHub Pages |
| バックエンド・DB | 原則不要 |
| ログイン | 不要 |
| スコア・設定の保存 | 必要に応じて localStorage |
| Docker | 原則不要 |
| 費用 | 無料枠・無料ツールを優先 |

- まずローカル環境で開発し、同じネットワーク内のスマホから動作確認する。
- 完成後はGitHub Pagesで公開し、URLから誰でも遊べる状態を目指す。
- 将来必要になれば、ホーム画面への追加（PWA）も検討する。

## 6. 開発の進め方

1. **プロトタイプ**：仮の色付き円で、落下・衝突・合体・スコア・ゲームオーバーなどを実装する。
2. **進化順カスタマイズ**：スタート画面で11段階を並べ替え、ゲームに反映する。
3. **電車ゲーム化**：11種類の画像、鉄道テーマのUI、効果音などを組み込む。
4. **調整・公開**：スマホで操作感・物理挙動・難易度を確認し、GitHub Pagesに公開する。

各段階で実機確認しながら進める。細かな実装方法や数値パラメータは、この文書では固定しない。

## 7. Codexへの依頼

この文書を**プロジェクトの概要・方向性**として扱ってください。ここにない細かな仕様を一度に決め打ちせず、必要な論点をユーザーと相談しながら段階的に実装してください。

特に優先すること：

- スマホで気持ちよく遊べる操作感と、スイカゲームに近い物理挙動。
- ゲーム開始前に11種類の進化順を自由に並べ替えられること。
- 画像や車種を後から容易に差し替えられるデータ設計。
- シンプルな構成、低コスト、メンテナンスしやすさ。
- 子どもが迷わず遊べる分かりやすさ。

※「スイカゲームに近い」はゲームの仕組み・遊び心地の目標であり、既存作品の画像・音源・ソースコードを無断流用する意図はありません。
